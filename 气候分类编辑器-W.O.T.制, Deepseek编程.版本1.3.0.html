标准不统一之处（各分类法差异）

1. 干旱阈值（B类）公式

  • Kottek等(2006) 未明确区分降水集中季节的阈值调整。
  • Peel等(2007)：Pthreshold = 2×MAT + 28（夏雨集中）或 +14（其他）。
  • Beck等(2018) 按冬夏降水比例细化阈值。
  • Trewartha 使用完全不同的公式。

2. C类冷月气温下限

  • Peel等(2007)：−3°C < Tcold < 18°C。
  • 部分文献使用 0°C 作为 C/D 分界。

3. 干季判定阈值

  • Peel 版要求 Psdry < 40 mm 且 < Pwwet/3。
  • Kottek 版用最干月与最湿月的比值。
  • Trewartha 将 C 类重新定义为“8个月以上 ≥ 10°C”。

4. 热带季风与草原的区分

  • Peel：Am 条件为 Pdry ≥ 100 − MAP/25。
  • Trewartha：Am 要求至少3个月降水 < 60 mm。

5. D类子类阈值

  • Peel：a/b/c/d 按最热月和月均温≥10°C月份数划分。
  • Trewartha 不使用 Thot ≥ 22°C 作为标志。

6. 极地类 E 细分

  • Peel：ET = 0 < Thot < 10；EF = Thot ≤ 0。
  • Trewartha 使用字母 F 表示极地类。

7. 周淑贞法与柯本法的核心差异

  • 周淑贞法基于斯查勒动力分类，以气团、锋面为发生学基础。
  • 周淑贞法独立设置热带、副热带、温带三个季风气候类型。
  • 周淑贞法将温带大陆性气候拆分为湿润（12）与干旱/半干旱（13a/13b）。
  • 周淑贞法将干旱气候按纬度带归入各带之内。

本程序默认采用柯本 Peel et al. (2007) 标准。周淑贞法采用周淑贞主编《气象学与气候学（第三版）》的气候名称体系。城市数据为气候代表值。
